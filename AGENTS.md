# slicc-extension

MV3 extension in `extension/` for six and seven. Seven: DNR lifts CORS on `*.sliccy.ai`; `sliccExtension.fetch` relays via the SW; `sliccExtension.cdp` proxies `chrome.debugger` minus protected origins. Six: `www.sliccy.ai` uses `externally_connectable` for the CDP bridge, secret fetch proxy, side panel. Six's TypeScript is in `six/` (origin: `six/upstream.json`); cherry is the pinned npm `@ai-ecoverse/cherry`, bundled. `scripts/build-six.mjs` bundles it byte-identically; no six tag or auto-bump. Roll forward only: B-SEC3 moved secrets to IndexedDB `records`; `check-six-floor.mjs` and `cws-publish.mjs` refuse older builds. Lint: `slicc-lint`. No comments anywhere. Agent guidance only here (≤1000 chars), no CLAUDE.md. Unit tests in gitignored `test/unit/`; `test/integration/` runs Chromium. Releases attach `artifacts/slicc-extension.zip`; with `CWS_PUBLISH_ENABLED`, release.yml publishes a release or a `publish_tag` dispatch, no environment gate.
