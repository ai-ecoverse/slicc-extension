# slicc-extension

Chrome MV3 extension in `extension/` serving both six and seven. Seven: static DNR rules add CORS headers on `*.sliccy.ai`, `sliccExtension.fetch` relays via the SW, `sliccExtension.cdp` proxies `chrome.debugger` with PRE-1 from slicc-browsers. Six: `www.sliccy.ai` connects via `externally_connectable` for CDP bridge, fetch proxy with secrets, and side panel. `six-import/` (gitignored) holds the snapshot from ai-ecoverse/slicc; `scripts/build-six.mjs` compiles it into `extension/six-sw.js`, `sidepanel.js`, `secrets.js`. Lint with `slicc-lint`. No comments in any file. Agent guidance lives only here (≤1000 chars). No CLAUDE.md. Unit tests in gitignored `test/unit/`; integration tests in `test/integration/` load the unpacked extension in Chromium. The publish job in release.yml is gated behind a `chrome-web-store` environment with required reviewers. Releases attach `artifacts/slicc-extension.zip`.
