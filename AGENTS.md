# slicc-extension

MV3 extension in `extension/` for six and seven. Seven: DNR rules lift CORS on `*.sliccy.ai`, `sliccExtension.fetch` relays via the SW, `sliccExtension.cdp` proxies `chrome.debugger` with slicc-browsers' protected origins. Six: `www.sliccy.ai` connects via `externally_connectable` for the CDP bridge, secret fetch proxy and side panel. Six's TypeScript lives in `six/` (origin in `six/upstream.json`); cherry is vendored in `six/cherry/` behind a tsconfig `paths` alias until `@ai-ecoverse/cherry` is on npm. `scripts/build-six.mjs` bundles it, byte-identical on rebuild; no six tag or auto-bump. Lint with `slicc-lint`. No comments in any file. Agent guidance only here (≤1000 chars), no CLAUDE.md. Unit tests in gitignored `test/unit/`; integration tests in `test/integration/` load it in Chromium. Releases attach `artifacts/slicc-extension.zip`; with `CWS_PUBLISH_ENABLED` true, release.yml publishes a new release or a dispatched `publish_tag`, no environment gate.
