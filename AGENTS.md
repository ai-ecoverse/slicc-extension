# slicc-extension

Chrome MV3 extension in `extension/` that lifts CORS for pages on `*.sliccy.ai`: a static DNR rule adds CORS response headers, and `globalThis.sliccExtension.fetch` relays requests through the service worker. `sliccExtension.cdp` on the same `slicc-fetch` port proxies `chrome.debugger` for senders `trusted()` already allows. README.md documents the handshake, relay, and CDP surface; keep it current. Lint with `slicc-lint`. No comments in any file. Agent guidance lives only in this AGENTS.md (≤1000 characters). Do not add CLAUDE.md. Unit tests stay in gitignored `test/unit/`; integration tests in `test/integration/` load the unpacked extension in Chromium. Releases attach `artifacts/slicc-extension.zip` to the GitHub release. No npm and no Chrome Web Store publish yet.
